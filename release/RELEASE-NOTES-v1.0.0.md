# ONDTF v1.0.0 — Stable Framework Specification

**Release date:** 28 September 2026  
**Specification maturity:** Stable  
**Evidence maturity:** E1 — repository-controlled reference/executable evidence

v1.0.0 establishes the first stable ONDTF normative contract. It adopts the frozen v0.9.0 candidate normative semantics without material semantic change. All nine repository-controlled v1.0 promotion gates are satisfied.

## Stable contract

- five frozen normative artefacts bound by exact Git blob SHA;
- 28 stable normative requirements and complete requirement-to-conformance coverage;
- six scoped conformance classes;
- five-layer interoperability and bounded recognition/equivalence semantics;
- deterministic validation and publication checks;
- v1.x compatible/material/breaking change classification;
- attributable errata and bounded emergency correction;
- evidence invalidation and gate reassessment after material normative change.

## Adoption tranche

This release adds an operational adopter front door and a minimal starter package as informative aids. They do not change the normative contract.

## Evidence boundary

Evidence maturity remains **E1**. ONDTF v1.0.0 does not assert independent implementation, externally demonstrated interoperability, operational deployment validation, production readiness, certification, or legal/regulatory approval.

## Upgrade from v0.9.0

No semantic migration is required for consumers of the frozen v0.9.0 candidate normative surface. Update version references to v1.0.0 and apply the active v1.x change-control model.
