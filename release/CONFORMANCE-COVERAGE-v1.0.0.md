# ONDTF v1.0.0 Conformance Coverage

v1.0.0 retains complete coverage of the 28 canonical requirements through stable `CT-CAN-*` assertions and six named `CCL-*` conformance classes.

The stable release does not permit an unqualified “ONDTF compliant” claim. Every claim remains scoped to version, applicable profile, conformance class, requirements, evidence and assessment authority.

Executable conformance machinery remains repository-controlled E1 evidence; it is not third-party certification or independent implementation evidence.
