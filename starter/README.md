# ONDTF Starter Package

This directory is an **informative, copyable starting point** for a bounded ONDTF adoption. It does not create conformance, approval, certification or legal authority.

1. Define scope in `profile.yaml`.
2. Record authorities/decision rights in `authority-model.yaml`.
3. Record lifecycle choices in `lifecycle.yaml`.
4. Bound assurance/evidence in `assurance-profile.yaml`.
5. Record recognition/interoperability in `recognition-profile.yaml`.
6. Record scoped claims in `conformance-claims.yaml`.
7. Keep material decisions in `decisions/` and evidence in `evidence/`.
8. Reconcile the result with Guided Framework Construction and the generated-package model.

Rules: leave unresolved decisions explicit; do not infer authority from credentials or technical control; never claim unqualified ONDTF conformance; TSMM/TIS are optional; repository E1 evidence is not adopter or third-party evidence.
